# NRIC Validator

A small, browser-only tool that checks the format and checksum of Singapore NRICs beginning with `S` or `T`.

The entered value is processed locally in the browser. This project has no server, analytics, or data storage.

## Publish with GitHub Pages

1. Create a new repository on GitHub and upload the project files. Repository visibility alone does not make the website private.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will display the published URL after deployment finishes.

Important: GitHub Pages websites are public by default, even when their source repository is private. Private Pages access control is an Enterprise Cloud feature. If this must be company-only, ask your GitHub administrator whether your organisation has that feature; otherwise deploy behind your company login.

## Use locally

Open `index.html` in a browser. No installation is required.
